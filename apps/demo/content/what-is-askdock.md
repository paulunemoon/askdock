# What Askdock is

Askdock is a chat widget that answers questions about **one site: yours**. It reads the pages you publish, and it will not answer from anything else. Ask it who won the World Cup and it says that isn't on this site.

It ships in two halves. The widget runs in the browser — a launcher and a panel. The route runs on your server, holds your API key, and talks to the model. The browser never sees a key.

## What it is not

- Not a general assistant. It has no tools, no web search and no memory between visits.
- Not a support desk. There is no ticketing, no handoff to a human, no inbox.
- Not hosted. There is no Askdock account and no Askdock server. You run it.

## Who it is for

Anyone with a site whose content already answers the questions people ask: a portfolio, a docs site, a product page, a handbook. The whole point is that the answers are made of pages you already wrote and can already point at.
